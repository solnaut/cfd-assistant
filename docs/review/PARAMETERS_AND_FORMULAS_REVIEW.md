## 1. 全局实现状态

- 当前参数计算模块采用“分类首页 -> 分类详情页 -> 单个计算器详情页”结构。
- 当前公式库 `/formulas` 读取计算器注册表中的同一份公式定义，不维护第二份公式文本。
- 内部计算统一转换到 SI 基准单位，显示时再按用户选择单位换算。
- 普通变量符号使用 Unicode 或显示符号，例如 `μ`、`ρ`、`ν`、`τw`、`uτ`、`Cf`。
- 公式区域使用 KaTeX 渲染，复制时使用原始 LaTeX。
- 用户界面不展示来源链接；来源保存在研究记录和本审核文档附录中。
- 所有已公开计算器当前状态均为 `available`，但部分工程适用性仍需要用户按项目背景审核。

## 2. 通用输入校验与单位规则

| 规则 | 当前实现 |
| --- | --- |
| 必填输入 | 缺失必填值时抛出错误 |
| 数值合法性 | 必须为有限数值，禁止 NaN 与 Infinity |
| 正值输入 | 长度、黏度、密度、热导率等需要大于 0 |
| 非负输入 | 速度、温差、面积、功率等按定义允许 0 的项使用非负校验 |
| 整数输入 | 层数、步数等必须为正整数 |
| 下拉选项 | 只能使用注册表中定义的有效选项 |
| 单位换算 | 通过 `toBaseValue` 先换算为 SI，再计算 |
| 输出显示 | 通过 `fromBaseValue` 与 `getUnitDisplaySymbol` 显示用户可读单位 |

常用显示单位包括：`Pa·s`、`kg/m³`、`m²/s`、`m/s`、`Pa`、`m`、`mm`、`W/(m·K)`、`W/(m²·K)`、`J/(kg·K)`。

## 3. 详细计算器审核卡片

### 3.1 y+ 与第一层网格高度

所属分类：近壁面与网格  
当前实现状态：已实现并公开。包含三种模式、平板外流、管道内流、边界层网格推荐方案。  
核心风险：这是初始网格估算工具，不是最终网格质量判据。最终应以后处理 y+ 分布、壁面剪切应力和边界层分辨率校核。

#### 输入参数

| 参数名称 | 符号 | 单位 | 是否必填 | 说明 |
| --- | --- | --- | --- | --- |
| 目标 y+ | y+ | 1 | 是 | 目标无量纲壁面距离 |
| 流动场景 | - | - | 初始估算必填 | 平板外流估算或管道内流估算 |
| 平板摩擦系数公式 | Cf,x | 1 | 平板外流必填 | 湍流平板、层流平板或用户自定义 Cf |
| 管道摩阻估算方式 | f, Cf | 1 | 管道内流必填 | 层流 Darcy、Blasius Darcy、自定义 Darcy、自定义 Fanning |
| 壁面剪切应力 | τw | Pa | 已知 τw 模式必填 | 已有仿真、实验或后处理值 |
| 密度 | ρ | kg/m³ | 是 | 流体密度 |
| 动力黏度 | μ | Pa·s | 是 | 流体动力黏度 |
| 参考速度 | U | m/s | 初始估算和已知 Cf 模式必填 | 平板自由来流速度或管内平均速度 |
| 特征长度 | L 或 x | m | 平板外流必填 | 当前实现使用 L 作为 x |
| 管径或水力直径 | D | m | 管道内流必填 | 圆管直径或非圆管水力直径 |

| Fanning 摩擦系数 | Cf | 1 | 自定义 Fanning 分支必填 | 内部换算为 Darcy f = 4Cf |
| 边界层增长率 | r | 1 | 否 | 默认 1.2，要求 r >= 1 |
| 推荐方式 | - | - | 否 | 自动总厚度、指定总厚度、指定层数 |

| 输出名称 | 符号 | 单位 | 说明 |
| --- | --- | --- | --- |
| 第一层中心距离 | y | m 或 mm | 壁面到第一层单元中心的距离 |

| Darcy 摩阻系数 | f | 1 | 管道 Darcy 分支输出 |

| 摩擦速度 | uτ | m/s | `sqrt(τw/ρ)` |
| 运动黏度 | ν | m²/s | `μ/ρ` |
| 网格层数 | n | 1 | 边界层推荐方案输出 |
| 实际总厚度 | Hn | m 或 mm | 等比层高累加 |

| Hn/D | - | 1 | 管道内流时显示 |

#### 使用公式

公共公式：

```latex
y^+=\frac{yu_\tau}{\nu}
```

```latex
u_\tau=\sqrt{\frac{\tau_w}{\rho}}
```

```latex
\nu=\frac{\mu}{\rho}
```

```latex
y=\frac{y^+\nu}{u_\tau}
```

```latex
h_1\approx 2y
```

初始估算：平板外流。

```latex
Re_x=\frac{\rho U x}{\mu}
```

```latex
C_{f,x}=0.0592Re_x^{-1/5}
```

```latex
C_{f,x}=\frac{0.664}{\sqrt{Re_x}}
```

```latex
\tau_w=\frac{1}{2}C_f\rho U^2
```

平板外流自动边界层厚度：

```latex
\delta=\frac{5x}{\sqrt{Re_x}}
```

```latex
\delta=\frac{0.37x}{Re_x^{1/5}}
```

初始估算：管道内流。

```latex
Re_D=\frac{\rho U D}{\mu}
```

```latex
f_D=\frac{64}{Re_D}
```

```latex
f_D=0.3164Re_D^{-1/4}
```

```latex
C_f=\frac{f_D}{4}
```

边界层网格方案：

```latex
h_i=h_1r^{i-1}
```

```latex
H_n=h_1\frac{r^n-1}{r-1}\quad (r\ne 1)
```

```latex
H_n=nh_1\quad (r=1)
```

```latex
n=\left\lceil\frac{\ln\left(1+\frac{H(r-1)}{h_1}\right)}{\ln r}\right\rceil\quad (r\ne 1)
```

#### 计算流程

1. 将密度、动力黏度、速度、长度等输入换算为 SI。
2. 计算运动黏度 `ν = μ/ρ`。
3. 按模式进入分支。
4. 初始估算平板外流：计算 `Re_x`，再按用户选择计算 `Cf,x`。
5. 初始估算管道内流：计算 `Re_D`，再按用户选择计算 Darcy f 或 Fanning Cf。
6. 已知 τw 模式：直接使用输入 `τw`，不重新估算壁面剪切。
7. 已知 Cf 模式：由 `τw = 0.5 Cf ρ U²` 计算壁面剪切。
8. 计算摩擦速度 `uτ`。
9. 计算中心距离 `y = y+ ν/uτ`。
10. 计算完整第一层厚度 `h1 ≈ 2y`。
11. 将 `h1` 传入边界层网格推荐方案。
12. 自动推荐模式：平板外流可用 δ 公式，管道内流使用工程预设层数。
13. 指定 H 模式：反算层数并向上取整。
14. 指定 n 模式：正向计算每层高度和累计厚度。

#### 适用范围与注意事项

- 平板自动 δ 仅用于零压梯度平板外流初始估算。
- 管道内流不套用平板边界层厚度公式。
- Blasius 管道公式当前作为光滑管湍流初始估算分支，页面会提示 Re 范围。
- Darcy f 与 Fanning Cf 不得混淆；当前内部使用 `Cf = f/4` 转换。
- 第一层中心距离 y 与完整第一层厚度 h1 不能混用。
- 结果只用于初始网格估算，最终应以后处理 y+ 分布校核。

#### 已知风险或待审核项

- 湍流平板和管道 Blasius 均为经验公式，需要用户结合实际 Re、粗糙度、压力梯度和几何判断。
- 不同软件对第一层高度可能指中心距离或完整厚度，当前页面同时输出并说明。
- 管道近壁总厚度没有使用统一自动公式，当前采用工程预设 `r=1.2, n=15`。

### 3.2 边界层网格等比增长

所属分类：近壁面与网格  
当前实现状态：已实现并公开。

| 输入参数 | 符号 | 单位 | 是否必填 | 说明 |
| --- | --- | --- | --- | --- |
| 第一层高度 | h1 | m | 是 | 等比序列第一层完整高度 |
| 增长率 | r | 1 | 是 | 每层高度比，要求 r > 0 |
| 层数 | n | 1 | 是 | 正整数 |

| 输出参数 | 符号 | 单位 | 说明 |
| --- | --- | --- | --- |
| 总厚度 | Hn | m | 所有层高之和 |
| 最后一层高度 | hn | m | 第 n 层高度 |

```latex
h_i=h_1r^{i-1}
```

```latex
H_n=h_1\frac{r^n-1}{r-1}
```

当 `r=1` 时：

```latex
H_n=nh_1
```

计算流程：读取 h1、r、n -> 生成层高序列 -> 计算总厚度 -> 输出最后一层高度和前 20 层摘要。  
校验规则：h1 > 0，r > 0，n 为正整数。  
适用范围：只描述数学层高序列，不判断真实边界层厚度或 y+。  
测试样例：h1=1 mm，r=1.2，n=5，Hn=0.0074416 m，hn=0.0020736 m，已通过。

### 3.3 CFL 与时间步长

所属分类：瞬态与时间步长  
当前实现状态：已实现并公开。

| 输入参数 | 符号 | 单位 | 是否必填 | 说明 |
| --- | --- | --- | --- | --- |
| 目标 CFL | CFL | 1 | 是 | 用户指定目标 Courant 数 |
| 特征网格尺寸 | Δx | m | 是 | 代表性单元长度 |
| 特征速度 | U | m/s | 是 | 局部或全局速度尺度 |

| 输出参数 | 符号 | 单位 | 说明 |
| --- | --- | --- | --- |
| 时间步长 | Δt | s | 按一维基础 CFL 关系估算 |

```latex
CFL=\frac{U\Delta t}{\Delta x}
```

```latex
\Delta t=\frac{CFL\Delta x}{U}
```

流程：单位换算 -> 校验 U > 0、Δx > 0 -> 计算 Δt。  
适用范围：一维基础估算；多维、局部速度和声速限制需用户另行判断。  
测试样例：CFL=1，Δx=10 mm，U=200 cm/s，Δt=0.005 s，已通过。

## 6. 审核建议

1. 优先审核 y+ 平板湍流、平板层流、管道 Blasius、Darcy/Fanning 转换和边界层总厚度推荐策略。
2. 审核 Nusselt 数当前是否只保留基础定义，避免用户误以为已包含具体换热关联式。
3. 审核层流管道压降是否需要在 UI 中更强提示 Re 范围。
4. 审核每个特征长度 L 的定义是否需要在页面中增加几何示意或选择项。
5. 后续新增经验关联式前，应先补充独立研究记录和至少两个可复现验证案例。
