## 1. 本阶段定位

本阶段只聚焦“参数计算”大模块，将其推进为可正式使用的工程计算模块。

本阶段不继续扩展 Fluent 功能导览。Fluent 导览只需保持当前可打开、可搜索、可点击的可用状态，不进行大规模重构，不扩展新的 Fluent 知识范围。

本阶段继续遵守现有项目规则：

- 只在当前项目目录内工作：`C:\Users\Administrator\Desktop\cfd-assistant`。
- 不推送 GitHub。
- 不部署 Cloudflare Pages。
- 不新增后端、不连接数据库、不接入外部 API。
- 不写入密码、令牌、验证码或账号凭据。
- 不把专业猜测伪装成确定结论。
- 未经权威来源支持或分支条件未明确的公式，不作为公开计算功能发布。
- 每个稳定代码阶段运行 `npm.cmd run lint`、`npm.cmd run test`、`npm.cmd run build`。
- 测试失败、lint 失败或生产构建失败时，不得声称完成。

## 5. 符号、单位和公式显示要求

### 5.1 普通变量符号

普通变量卡片、变量说明表、结果摘要和中间量列表中，变量符号应显示为真实 Unicode 字符或清晰数学文本。

示例：

| 不允许的普通文本显示 | 应显示为 |
| --- | --- |
| `\mu` | `μ` |
| `\rho` | `ρ` |
| `\nu` | `ν` |
| `\tau_w` | `τw` 或更好的数学排版 `τ_w` |
| `\alpha` | `α` |
| `\beta` | `β` |
| `\omega` | `ω` |
| `\Delta t` | `Δt` 或更好的数学排版 `Δt` |

实施要求：

- 公式 LaTeX 字符串仍保留反斜杠形式，用于 KaTeX 渲染和复制。
- 普通变量显示字段必须与 LaTeX 字段分离。
- 可新增 `displaySymbol`、`plainSymbol` 或等价字段。
- 变量符号区域使用 Times New Roman、Cambria Math 或合适数学字体。
- 不得在普通文本区域直接展示 `\mu`、`\rho` 等 LaTeX 源码。

### 5.2 单位显示

单位显示必须使用工程可读格式：

| 当前常见 ASCII 写法 | 用户界面建议显示 |
| --- | --- |
| `Pa*s` | `Pa·s` |
| `kg/m^3` | `kg/m³` |
| `m^2/s` | `m²/s` |
| `W/(m*K)` | `W/(m·K)` |
| `W/(m^2*K)` | `W/(m²·K)` |
| `J/(kg*K)` | `J/(kg·K)` |
| `um` | `μm` |
| `degC` | `°C` |

实施要求：

- 单位换算 ID 可以继续使用稳定 ASCII 标识，例如 `kg/m^3`。
- 用户界面应使用独立 `displaySymbol` 或等价字段。
- 复制计算摘要时优先使用用户可读单位符号。
- 内部计算继续统一使用 SI 单位。

### 5.3 公式渲染

- 公式区域使用 KaTeX 或等效数学渲染方式。
- 每条公式必须保存原始 LaTeX 字符串。
- 公式区支持复制原始 LaTeX。
- 公式库和计算器详情页必须共用同一份公式定义数据。
- 公式定义、计算函数和测试案例必须保持一致。

## 8. y+ 与第一层网格高度专项要求

y+ 计算器不是单一通用公式工具。本阶段必须先完成研究，再决定可公开分支。

### 8.1 必须研究的问题

研究记录必须覆盖：

- y+ 定义。
- 摩擦速度 `u_τ`。
- 壁面剪切应力 `τw`。
- 第一层单元中心距离 `y`。
- 第一层完整单元厚度 `h1` 与中心距离 `y` 的关系。
- 动力黏度 `μ` 与运动黏度 `ν` 的输入方式。
- 外流平板经验关联式。
- 管内流动摩阻系数方法。
- Darcy 摩阻系数与 Fanning 摩阻系数的区别。
- 层流、湍流和转捩条件。
- 结果仅作为初始网格估算，最终应以 Fluent 后处理 y+ 分布校核。

### 8.2 建议公开分支

若来源和验证充分，优先考虑以下分支：

| 分支 | 输入方式 | 优点 | 风险 |
| --- | --- | --- | --- |
| 用户输入壁面剪切应力 | `τw`、`ρ`、`μ` 或 `ν`、目标 y+ | 最少经验假设 | 用户必须已有可靠 `τw` |
| 用户输入摩擦系数 | `Cf` 或 `f_D/f_F`、`ρ`、`U`、`μ` 或 `ν`、目标 y+ | 可控且透明 | 必须清楚 Darcy/Fanning/Cf 定义 |
| 平板外流估算 | `U`、`L`、物性、目标 y+、层流/湍流场景 | 常见初始网格估算 | 局部/平均 Cf、Re 范围必须明确 |
| 管内流动估算 | `D`、`U` 或流量、物性、目标 y+、摩阻因子方法 | 管路场景实用 | 层流/湍流、粗糙度和摩阻关联式需谨慎 |

若任何分支存在来源冲突或适用范围不清：

- 不强行做成唯一通用公式。
- 不公开该分支的自动计算。
- 将分支保留在内部研究记录和后续待办中。

### 8.3 y+ 输出要求

y+ 页面最终至少输出：

- Reynolds 数。
- 摩擦系数或所用中间参数。
- 壁面剪切应力。
- 摩擦速度。
- 第一层单元中心距离。
- 推荐第一层完整单元厚度。
- 适用范围。
- 注意事项。

### 8.4 y+ 页面说明要求

页面必须清楚表达：

- 结果是初始网格估算，不是最终质量保证。
- 最终应以后处理 y+ 分布校核。
- 第一层中心距离和完整第一层厚度不能混用。
- Darcy 摩阻系数和 Fanning 摩阻系数不能混用。
- 不同湍流模型和近壁处理对目标 y+ 有不同要求。

## 9. CFD 公式库

新增独立板块，名称可使用：

- CFD 公式库
- 公式汇总

### 9.1 路由建议

建议新增路由：

```text
/formulas
```

也可以根据现有导航命名为：

```text
/formula-library
```

最终命名应保持中文导航清晰。

### 9.2 页面功能

公式库不提供输入、输出或计算结果，只集中展示本应用使用到的 CFD 公式。

每条公式显示：

- 公式名称。
- 所属分类。
- 简短用途说明。
- KaTeX 渲染公式。
- 复制 LaTeX 按钮。
- 变量说明。
- 适用范围简述。

公式库不显示外部来源链接。

### 9.3 数据一致性

- 不允许在公式库中手写另一份公式。
- 公式库、计算器页面、计算函数和测试必须能追溯到同一公式 ID。
- 若某个计算器有多个分支公式，公式库应按分支展示并说明分支条件。

1. 正式标准。
2. 权威教材。
3. 官方理论指南。
4. 大学课程资料。

- y+ 相关摩擦系数。

| 层级 | 测试重点 |
| --- | --- |
| 纯函数测试 | 数值计算、分支、非法输入、边界值 |
| 单位测试 | SI 归一化、输出单位换算、显示符号 |
| 元数据测试 | 公式 ID、LaTeX、变量符号、单位显示、研究记录关联 |
| 页面测试 | 输入、计算、重置、复制按钮、公式渲染 |
| 浏览器冒烟测试 | 路由、控制台 error、公开页面无 TODO/来源链接/乱码 |

## 12. 用户界面内容规则

公开页面不得显示：

- 开发 TODO。
- 内部审核状态。
- 研究备注。
- 源码路径。
- 外部来源链接列表。
- 只适合维护者阅读的公式争议说明。

可显示：

- 产品化的空状态。
- 适用范围。
- 工程注意事项。
- 用户需要理解的限制条件。
- 计算结果只是初始估算的说明。

内部文档可以保留研究状态、来源冲突、待确认问题和后续待办。
