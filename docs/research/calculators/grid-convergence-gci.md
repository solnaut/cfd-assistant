# 三网格收敛指数

- 依据 [NASA Glenn 的空间收敛指南](https://www.grc.nasa.gov/www/wind/valid/tutorial/spatconv.html)，三网格安全系数为 1.25。相对 GCI 以当前细一级监测值作归一化，渐近区间比值接近 1 可用于诊断。
- 不等细化比由单项误差模型 `φ(h) = φ₀ + C hᵖ` 的两组差分比求表观阶。默认例取 3D 单元数 1,728,000 / 512,000 / 216,000 和监测值 100.25 / 100.5625 / 101。解析外推 100，表观阶 2。
- 该实现适用于系统性细化、单调趋势和正表观阶。近零差值及零归一化基准会拒绝计算。迭代误差、时间误差和模型不确定度需另行检查。
