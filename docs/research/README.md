# Research Records

本目录用于保存 CFD Assistant 的公式、验证案例和 Fluent 功能说明来源记录。这里的内容服务于内部研究、审核和维护流程，不直接面向最终用户展示。

## 目录结构

```text
docs/research/
  calculators/   CFD 参数计算器公式、单位、适用范围与验证案例
  fluent/        Fluent 功能导览条目来源、版本、章节与改写记录
```

## 基本规则

- 公开页面不得显示未审核公式、内部审核状态、开发过程说明或 TODO。
- 未能被权威来源支持的公式，只能保留在研究记录或页面结构中，不实现为公开计算结果。
- 所有正式计算器必须保存公式来源、变量定义、SI 单位、适用范围、假设、验证案例和审核状态。
- 所有 Fluent 解释必须使用自己的语言概括，不复制官方长段文字，不使用 Ansys 或 Fluent 官方 Logo、截图或图标。
- 发现来源冲突时，记录冲突点并暂停该公式或知识条目的公开实现，继续其他独立任务。
- 文档、源码和网页必须保持 UTF-8 编码，避免中文、英文、公式符号和单位显示乱码。

## 完成导向

最终产品目标是让用户能够在网页中输入数据，按已验证公式自动计算，得到结果、中间量、公式、变量说明、适用范围、来源和工程说明；Fluent 教学板块应覆盖主要单相流动与传热工作流中的常见界面节点、按钮和选项，并保持专业、清晰、易用的界面体验。
