# CFD Assistant Product Spec

## 产品定位

CFD Assistant 是面向 CFD 工程人员和 Ansys Fluent 初学者的第三方网页辅助工具。第一阶段以静态网页发布，用户无需安装软件，通过固定链接在手机、平板或电脑浏览器访问。

本项目不连接 Fluent，不执行真实仿真，不冒充 Ansys 官方产品。

最终产品应成为一个可实际使用的工程辅助网页应用：用户能够输入数据，选择单位，根据已验证公式自动计算，获得结果、中间量、公式、变量说明、适用范围、来源和工程说明；Fluent 教学板块能够覆盖主要单相流动与传热工作流中的常见界面节点、按钮、下拉项、复选框和对话框选项，并保持清晰、专业、易用和无乱码。

## 核心功能

### CFD 参数计算

目标是提供单位换算、公式计算、结果展示和验证明确的工程计算器。计划包括：

- y+ 与第一层网格高度计算
- 边界层网格计算
- CFL 与时间步长计算
- Reynolds 数
- Mach 数
- Prandtl 数
- Peclet 数
- Rayleigh 数
- Grashof 数
- Fourier 数
- Biot 数
- 后续可能增加管道压降和旋转机械时间步长

每个计算器最终应包含参数输入、单位选择、输入校验、计算按钮、清空按钮、中间结果、最终结果、复制结果、公式、参数含义、适用范围、工程注意事项、示例数据和自动测试。

公式和适用范围必须有权威来源记录，并由用户或项目维护流程审核。Codex 可以先检索正式标准、权威教材、官方理论指南、同行评审论文、大学或国家实验室资料并形成研究记录；未经确认的内容不得实现为公开的确定计算逻辑。

### Fluent 功能学习导览

目标是帮助 Fluent 初学者理解界面功能分类和设置项。页面使用自主设计的教学界面，通过点击目录节点或设置项读取本地知识库条目并展示解释。

知识条目包含唯一 ID、所属模块、英文名称、中文名称、菜单路径、一句话说明、功能原理、使用场景、主要选项、选项差异、对精度稳定性和计算成本的影响、前置条件、常见错误、检查建议、关联功能、关联计算器、适用 Fluent 版本、内容版本、更新时间和搜索关键词。

公开页面不显示 TODO、内部审核状态或开发过程说明。未审核内容只能保留在知识库草稿、研究记录或开发文档中；面向用户的界面使用自然、克制的空状态表达。

## 页面范围

- 首页：两个主要入口，参数计算和 Fluent 功能导览。
- 参数计算：分类首页、分类详情页和单个计算器详情页。
- Fluent 功能导览：左侧功能树、中间教学模拟设置面板、右侧解释面板；移动端改为适合小屏幕的分步阅读与详情布局。
- 预留：关于项目、更新记录、使用说明、内容版本、反馈方式。

## 质量要求

- 网站在手机、平板和电脑上都应保持可读、可操作和视觉一致。
- 中文、英文、公式、单位和符号必须使用 UTF-8 正确显示，不得出现乱码。
- 页面、计算逻辑、单位换算、数据模型和知识库内容必须分离。
- 公开页面不得显示内部 TODO、未审核状态、源码路径、开发规则或调试说明。
- 每个稳定阶段必须通过 lint、test、production build 和浏览器冒烟测试。

## 发布目标

本地项目通过 GitHub 仓库连接 Cloudflare Pages 自动部署。每次推送后重新构建，公开链接保持不变。成熟后尽量复用代码封装 Android 应用。
